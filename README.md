<h1 align="center">OKUJIN MUSIC</h1>

<p align="center">A dark, fully customizable music player for Windows, built for your MP3, FLAC, WAV, M4A and OGG files.</p>

---

## Installation

1. Go to [**Releases**](../../releases/latest) and download `OKUJIN-Setup.exe`.
2. Run it and click **INSTALLER**.
3. On first launch, enter your license key (`OKUJIN-XXXXX-XXXXX-XXXXX-XXXXX`). You only need to enter it once.

OKUJIN installs into your user folder, with no admin rights needed, and adds a shortcut to your desktop and Start menu.

> Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**.

## Updates

OKUJIN checks for a new version at startup and downloads it in the background. When it's ready, a card pops up: click **REDÉMARRER** (restart). There's nothing to reinstall, and your settings, playlists, favorites and stats are kept.

You can also check manually in **Settings → Infos**.

## Adding your music

- **Add a folder**: OKUJIN scans the whole folder, including subfolders. You can add several (**Settings → Bibliothèque**).
- **Drag and drop** files or a folder onto the window.
- Use the **+ FICHIERS** button at the bottom left.

Folders are watched, so a track you add to one shows up automatically. OKUJIN reads tags (title, artist, album, cover art, track number, year) to organize your library.

**Formats:** MP3, FLAC, WAV, M4A / AAC, OGG / Opus, WebM.

## Features

**Library**
- Tracks, Albums and Artists, with a page for each album and artist
- Global search (Ctrl+F)
- Sort by title, artist, album, duration or date added

**Playlists**
- Create, rename, duplicate and delete
- Custom cover: art from one of the playlist's tracks, an image from your PC, or an image dropped onto the cover
- Reorder tracks with drag and drop
- Drag a track onto a playlist in the sidebar to add it
- Auto playlists: **Favorites ♥**, **Recent**, **Most played**

**Playback**
- Queue: "Play next", "Add to queue", reorderable
- Shuffle that keeps the original order, and repeat (all / one)
- 10-band equalizer with presets (Bass boost, Vocal, Electro, Rock, Hip-hop, Lofi…)
- Crossfade between tracks
- Volume normalization
- Sleep timer (15 to 90 minutes, or end of track)
- Resumes where you left off
- Always-on-top mini player (Ctrl+M)

**Lyrics**
- Synced lyrics: put a `.lrc` file with the **same name** as the track in the same folder
  (`My song.mp3` → `My song.lrc`). A `.txt` file works for plain lyrics.
- Lyrics embedded in the file's tags are read too.

**Customization** (Settings, **O** key)
- Accent color: automatic (follows the cover art) or fixed
- Title, subtitle, font, size, color and shimmer effect
- Backgrounds: GIFs or images (import your own), blurred cover art, or none; adjustable blur, fade and auto-change
- Visualizer: mirror, bars or wave
- Cover shape: square, rounded, or a spinning vinyl
- Resizable sidebar (double-click its edge to reset)

The interface is in French.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `Space` | Play / pause |
| `N` / `P` | Next / previous track |
| `←` / `→` | Seek back / forward 5 s |
| `↑` / `↓` | Volume |
| `M` | Mute |
| `S` | Shuffle |
| `R` | Repeat |
| `H` | Add / remove favorite |
| `Q` | Queue |
| `L` | Lyrics |
| `E` | Equalizer |
| `O` | Settings |
| `Delete` | Next background (`Shift+Delete`: previous) |
| `Ctrl+F` | Search |
| `Ctrl+M` | Mini player |
| `Esc` | Close |

Keyboard media keys (play, next, previous) work too.

## Uninstall

**Windows Settings → Apps → OKUJIN → Uninstall.**
Your music files are never touched.

## Requirements

- Windows 10 or 11 (64-bit)
- ~250 MB of disk space
